# Screens

This folder is for future Mobile Pilot 1 screens.

Initial screens should be limited to accepted Pilot 1 workflows: setup/reference data, manual harvest, manual material use, manual inventory count, local history, and export/recovery-copy flow.

For existing-record edits, screens should show details first and keep edit forms anchored to the selected item: hide the form until the user taps Edit, render it directly below that Edit action, and close it after Save or Cancel. Avoid a single stationary edit form at the top or bottom of a page for records selected elsewhere.

Do not add AI, server sync, authentication, shared listing, or messaging screens.
